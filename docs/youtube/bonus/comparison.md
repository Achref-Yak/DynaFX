# Bonus: DynaFX vs Other Tools - When to Use What

**What it does:** Compare DynaFX to SimPy, AnyLogic, Vensim, and custom code.

**Duration:** 12-15 minutes

**Hook:** "Is DynaFX the right tool? Let's compare."

---

## Script Outline

### 0:00 - Hook (30 sec)
- "There are many simulation tools. When should you use DynaFX?"

### 0:30 - Comparison Matrix (2 min)
| Feature | DynaFX | SimPy | AnyLogic | Vensim |
|---------|--------|-------|----------|--------|
| SD | Yes | No | Yes | Yes |
| ABM | Yes | No | Yes | No |
| DES | Yes | Yes | Yes | No |
| Knowledge Graph | Yes | No | No | No |
| Closed Loop | Yes | No | No | No |
| Python | Yes | Yes | Partial | No |
| Open Source | Yes | Yes | No | No |
| Free | Yes | Yes | No | No |

### 2:30 - When DynaFX Wins (4 min)
- "When you need multiple paradigms in one model."
- "When knowledge graphs matter."
- "When you need closed-loop reasoning."
- "When you want Python-native."

### 6:30 - When SimPy Wins (2 min)
- "Pure DES with no SD or ABM."
- "Large community, many examples."
- "Simpler API for queueing."

### 8:30 - When AnyLogic Wins (2 min)
- "GUI-based model building."
- "Commercial support."
- "Enterprise deployment."

### 10:30 - When Vensim Wins (2 min)
- "Pure SD with built-in optimization."
- "Academic standard."
- "Stella integration."

### 12:30 - Decision Flowchart (1 min)
- "Do you need knowledge graphs? -> DynaFX"
- "Do you need queues? -> SimPy or DynaFX"
- "Do you need a GUI? -> AnyLogic"

### 13:30 - Outro (30 sec)
- "Choose the right tool for the job."
